# FitLog

FitLog is a modern workout planning and tracking app built with Next.js and Tailwind CSS. It helps users browse exercises, build a daily plan, save workouts for later, and track totals for a focused training session.

## Technologies Used
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Browser localStorage for plan persistence

## Key Features
1. Browse a responsive library of workouts with category and training stats.
2. Open workout detail pages with equipment, difficulty, specs, and instructions.
3. Build a daily workout plan with a five-workout limit and live summary metrics.
4. Save workouts for later and manage saved and planned lists separately.
5. Sort workouts by duration, calories, or rating; mark plan items done or remove them.
6. Persist plan and saved lists in localStorage, with toast feedback and loading/404 states.

## Run Locally
Install dependencies with `pnpm install`, then start the development server with `pnpm dev`. Use `pnpm lint` and `pnpm build` to check the app before deployment.
